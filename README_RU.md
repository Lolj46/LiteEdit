# LiteEdit 0.3.0

Минималистичный Android-редактор изображений. В проект включены Gradle-конфигурация, Kotlin-исходники и минимальные ресурсы главного экрана.

## Возможности
- Импорт изображений через системный выбор файлов.
- Обрезка по процентам, поворот на 90°, отражение по горизонтали и вертикали.
- Яркость, контраст, насыщенность и размытие.
- Добавление текста, изменение размера, Undo/Redo и сброс.
- Экспорт JPEG/PNG.

## Сборка
Требуются JDK 17, Android SDK Platform 35, Build Tools 35.0.0 и Gradle 8.13.

```bash
gradle --no-daemon :app:assembleDebug
```

Готовый APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Ограничения
Обрезка задаётся численно, текст располагается ближе к нижнему краю. Экспорт ограничен 5000 px по длинной стороне и 10 Мп ради устойчивой работы на устройствах с ограниченной памятью. Оригинал не перезаписывается.
